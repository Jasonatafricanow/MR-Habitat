# Xiyue Home 结构校正

2026-09-09。依据原始两张设计图，以及用户后来补充的玄关清晰局部图。此记录取代 inventory audit 中关于结构完成的判断。

## 本轮实际修改

- 玄关：左墙与靠客厅的横向短墙形成 L 形转角。镜子挂短墙朝入户方向的一面；长凳沿左墙；挂衣物归到右侧厨房隔墙。短墙右侧保留 0.9 个作者单位的通口。主入口嵌回前沿墙线，取消伸到地板外的门扇。
- 厨房与玄关前沿对齐，厨房向内延伸至公共通道。客厅东南角按厨房边界切掉重复地板；厨房入口位于其北边。
- 卧室：床头靠西，床长轴为东西向，床头柜及灯跟随归位；卧室与卫浴共墙补齐，卧室东侧门洞保持明确。
- 卫浴：清晰局部图显示镜柜贴卧室/卫浴共墙，因此撤销本轮中途对“南墙洗手台”的误读。最终镜柜在北侧共墙，龙头背向与墙面一致；马桶在北侧另一边，淋浴在西南，木凳在东南。东侧 0.9 单位门洞有完整墙段限定。
- 外轮廓：补窗边与书房的阶梯墙线、客厅北侧外墙、走廊南侧边界。窗、软木板和厨房层架跟随相应房间移动。高背板不再作为独立装饰墙替代房间边界。

## 显示与运行

近侧墙仍作剖切显示；完整保留的墙段高 2.65，卫浴共墙剖切高 1.95，低墙高 0.72。墙的实际平面碰撞不随显示高度开放。调整了默认俯角，并允许转到接近正俯视，便于核对围合。

Projection bindings 没有参与布局。人物接近点随完成的空间移动。Xiyue 使用 0.1 的导航网格以保留 0.9 门洞，Paperwood 保持原默认网格；修正了路径边缘取整导致的途中重新寻路失败，候选连接段仍逐段检查碰撞。

原图标注近似尺寸，正投影和透视图也存在细节差异。本次优先恢复房间邻接、墙体转角、入口和主要家具朝向；不声称测绘级尺寸复刻或达到参考图材质完成度。
